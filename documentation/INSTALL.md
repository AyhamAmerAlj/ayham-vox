# التثبيت والاستخدام (V0.1)

## 1. تحميل الـ APK
من GitHub ← Actions ← آخر تشغيل ناجح ← Artifacts. التحميل يكون ملف zip فيه الـ APK.

## 2. التثبيت
- فك الضغط وثبّت `android-phone-debug.apk` على هاتف Android.
- ثبّت `android-tv-debug.apk` على التلفزيون (مثلاً بتطبيق Send Files to TV أو USB).
- فعّل "التثبيت من مصادر غير معروفة" إذا طلب.

## 3. التجربة
1. الهاتف والتلفزيون على نفس شبكة الواي فاي.
2. افتح تطبيق التلفزيون: يعرض **عنوان التلفزيون** و**رمز الاقتران**.
3. في الهاتف: أدخل العنوان والرمز واضغط **اتصال**.
4. اضغط **ابدأ التجربة** ← تظهر ترجمات تجريبية على التلفزيون.
5. بريموت التلفزيون: ▲▼ حجم الخط، OK ينقل الترجمة أعلى/أسفل.

## ملاحظات V0.1
- الترجمة تجريبية (قاموس صغير)، لا يوجد ميكروفون ولا AI بعد.
- QR Code غير موجود بعد (يُضاف V0.4)، الاقتران برمز من 6 أرقام.
